# AIと進める3D CAD・ロボットシミュレーション

FreeCADを使い、図面からのモデリング、治具・設備の組立設計、部品表づくり、ロボットの配置・教示検討までを、AIとの対話でつなぐシステムを開発しています。

CodexとClaudeで、CAD作業と単一ロボットSIMを段階的に試作しています。形状づくり、組立、部品表、調達資料、ロボット動作の検討を、一連の流れで扱うことを目指しています。

## 試作で確認したこと

### 図面から3D部品をモデリング

2D図面や図面画像の寸法を読み取り、FreeCADで編集可能な3D部品を作成できます。スケッチ、押出し、穴、切欠きなどを組み合わせ、寸法が不足する箇所は解釈した内容と未確定寸法を分けて扱います。小部品では、部品生成から組立、回転軸の設定、可動確認まで試しています。

### アルミフレーム作業台をアッセンブリー設計

50角アルミフレームを使った500×500×高さ700mmの作業台を見本として、フレーム、天板、接合金具、ボルト、ナット、脚部を部品別に組み立てました。共通ベースへボルト固定する仕様と、床置きでレベリング・アンカーを使う仕様を分け、寸法を変更して再利用できる設計を進めています。

### アッセンブリーを分解して製作資料へ

保存したアッセンブリーから構成部品と数量を整理し、部品表、フレーム切断リスト、要確認事項、部品別DXFを作る試作を行っています。

### MISUMIなどへの見積依頼用リストを作成

候補品番、数量、切断長、加工内容、未確定事項をまとめ、MISUMIなどへの見積依頼に使う一覧と依頼文の下書きを作れます。公開寸法を参考にした独自近似モデルと、ユーザーが取得した公式CADは区別して管理します。

### ロボットセルの配置候補を自動計算

床基準、ロボットの基準姿勢、作業台・治具・ワークの高さを使ってセル配置候補を計算し、限定した見本セルでは配置と保存まで確認しています。ロボット架台や作業台の高さ、ワーク位置は変更可能な入力として設計しています。

### 工具モデルの取付と仮TCP設定

6軸ロボットのJ6フランジ座標を基準に仮想工具を取り付け、ロボット姿勢と工具・TCPを連動させる試作をFreeCADで確認しています。仮TCPの位置・向き、世界座標、方向軸を計算・表示し、限定試験ではCADへ保存しました。関節、BASE、TOOLの各操作モード、Tagによる教示点管理、接近・作業・退避を含む経路検討へつなげています。

## 現在のSIM開発

FANUCの20kg前後クラスを想定した6軸モデルで、個別軸操作、TCP表示、TagとProgram、経路補間、関節余裕、工具・治具間の距離確認を開発しています。CADモードとSIMモードを切り替え、人が操作しやすいFreeCAD内の専用画面へ整理している段階です。

> 現在は試作確認の範囲です。実機運転・安全性を認定するものではありません。
