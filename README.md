# AIと進める3D CAD・ロボットシミュレーション

FreeCADを基盤に、言葉で伝えた指示から部品やワーク、仮の治具を3Dで形にし、ロボットの動きを検討する開発プロジェクトです。AIと対話しながら、設計の意図を確認し、形状・配置・動きを段階的に確かめる使い方を目指しています。

## 現在の試作実績

提供された2枚の図面から、解釈した寸法や未確定箇所を明記した3Dモデルを作成しました。FANUCの公開モデルの6軸定義に基づく機体表示・関節連動も確認しています。Codex CLIからのMCP操作では、姿勢変更、保存、別読込みによる確認、正常終了までを検証しました。

## 開発中のこと

MCP設定への登録と、別プロセスでの初期化・ツール検出は確認済みですが、Codex Desktop上からの実操作は未確認です。姿勢更新は約2.7〜2.9秒で、高速化は開発課題です。メーカー製クランプの可動、全軌跡の安全確認、実工具の基準点や実機条件も未確定です。

将来は「この部品を作り、治具に配置して、ロボットの動きを確認する」という一連の検討を対話で進められることを目指します。現在は試作段階で、完成商品や実機運転用の仕組みではありません。
