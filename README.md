# AIと進める3D CAD・ロボットシミュレーション

FreeCADを使い、図面からの部品づくりとロボットの動作検討を、AIとの対話で進めるシステムを開発しています。

CodexとClaudeで、3Dモデル化・ロボットSIM・保存確認の試作を進めています。試験用のロボット動作について、AIからの操作と保存・再読込を確認しました。

部品表からのDXF出力を試作し、教示と溶接条件の入力画面を整備しています。

現在は仮形状による開発・検証段階です。操作の拡充、反応速度、軌跡の検証を改善中で、実機運転の対応は未確認です。

アルミフレームの作業台と、FreeCAD内のSIM操作画面を試作しています。

FreeCADの操作確認と、開発仕様書の整理を進めています。

ロボットの各軸操作を追加し、既存の操作と併せて確認しました。


## 開発状況（2026-10-14）

教示データの保存・読み込み・復元を検証し、操作画面から独立したSIM基盤の整備を進めています。対応範囲を確認しながら開発を継続します。
